# Генератор статей для линкбилдинга

Программа для Windows, которая пишет гостевые SEO-статьи со ссылкой на проект через нейросеть Google Gemini и сама проверяет каждую статью по ТЗ.

**Как это выглядит в работе:** вы копируете строки из Excel-плана, нажимаете «Сгенерировать», и программа по одной пишет статьи: на языке донора, с одной ссылкой с нужным анкором и шестью упоминаниями бренда, по рабочему промпту команды. Готовый HTML вы копируете одной кнопкой и вставляете в админку сайта-донора.

Программа бесплатная, работает на вашем компьютере, и все данные хранятся только у вас.

## Быстрый старт — 5 минут

1. Скачайте `ArticleGenerator-1.2.0-win-x64.zip` в разделе **[Releases](../../releases)** (справа на странице репозитория).
2. Распакуйте архив, откройте папку `ArticleGenerator` и запустите **`ArticleGenerator.exe`**.
3. Получите бесплатный ключ на [aistudio.google.com](https://aistudio.google.com) → **Get API key**, вставьте его в **Настройки → API-ключ** и нажмите **Проверить**.
4. На вкладке **Задачи** нажмите **«+ Вставить из Excel»**, скопируйте строки плана в Excel (`Ctrl+C`) и вставьте их в программу (`Ctrl+V`).
5. Нажмите **«Сгенерировать»**. Готовые статьи появятся на вкладке **Статьи**, там же кнопка **«Копировать HTML»**.

Подробности по каждому шагу ниже.

## 1. Установка

Установщик и права администратора не нужны.

1. Откройте **[Releases](../../releases)** и в последнем релизе скачайте `ArticleGenerator-<версия>-win-x64.zip` (около 130 МБ).
   > Файлы в самом репозитории — исходный код, их скачивать не нужно. Готовая программа лежит только в Releases.
2. Распакуйте zip **в постоянную папку**, например `Документы\ArticleGenerator`: правый клик по архиву → «Извлечь все…». Не запускайте программу прямо из архива: Windows распакует её во временную папку, и программа может не запуститься или пропасть.
3. Откройте папку и запустите **`ArticleGenerator.exe`**.
4. Если появилось синее окно **«Система Windows защитила ваш компьютер»**, нажмите **«Подробнее» → «Выполнить в любом случае»**. Программа не подписана платным сертификатом, это нормально. Окно появляется только при первом запуске.
5. **Ярлык на рабочий стол:** правый клик по `ArticleGenerator.exe` → «Отправить» → «Рабочий стол (создать ярлык)». Можно и закрепить на панели задач.

## 2. Ключ Gemini

Статьи пишет нейросеть Google Gemini. Для неё нужен ключ API. Он бесплатный и создаётся за минуту.

1. Откройте [aistudio.google.com](https://aistudio.google.com) и войдите своим Google-аккаунтом.
2. Нажмите **Get API key** → **Create API key**. Скопируйте ключ: строка, которая начинается с `AIza…`.
3. В программе откройте **Настройки** → вставьте ключ в поле **API-ключ** → нажмите **Проверить**.
4. Должно появиться **«✅ Ключ работает, модель … отвечает»**. Если написано ❌, проверьте, что ключ скопирован целиком.

> **У каждого сотрудника должен быть свой ключ.** Лимиты бесплатного тарифа считаются на ключ: если пользоваться одним ключом вдвоём, вы будете тратить лимит друг у друга.
>
> **Ключ никому не пересылайте.** Он хранится только на вашем компьютере.

## 3. Работа каждый день

### Шаг 1. Вставить задачи из Excel

1. На вкладке **Задачи** нажмите **«+ Вставить из Excel»**. Откроется поле вставки.
2. В Excel выделите нужные строки «Плана работы» **целиком** (колонки A…L) и нажмите `Ctrl+C`.
3. Щёлкните в поле «Нажмите сюда и вставьте» и нажмите `Ctrl+V`.

Программа сама берёт из строки три колонки:

| Колонка плана | Что это | Пример |
|---|---|---|
| **A — Domain** | донор: сайт, где будет опубликована статья | `paradisechick.com` |
| **C — Anchor** | анкор: текст ссылки (голый URL — тоже нормальный анкор) | `betano casino` |
| **K — Project** | акцептор: сайт, на который ведёт ссылка | `https://betano-nl.com/` |

Остальные колонки (логины, цены и т.д.) программа не читает.

- **Заголовки колонок копировать не обязательно.** Если они есть, программа их распознает.
- **Можно вставлять и три колонки** в порядке Донор · Анкор · Проект.
- **Если в ячейке ссылка с подписью** (например, текст «Whytewold Emporium», а за ним ссылка на сайт), берётся сам адрес ссылки.
- **Одинаковые строки — это отдельные статьи.** 5 одинаковых строк дадут 5 задач.
- **Повторная вставка того же куска плана ничего не продублирует.** Программа напишет «пропущено дублей: N». Удобно: можно каждый день вставлять план целиком, и добавятся только новые строки.

### Шаг 2. Проверить язык и бренд

Под полем вставки появится сообщение, например: «Добавлено задач: 12 · всё готово к генерации». В таблице у каждой строки есть **язык донора** (на нём пишется статья), **язык ссылки** и **бренд**.

Цвет поля языка подсказывает, нужно ли что-то делать:

| Цвет | Что значит | Что делать |
|---|---|---|
| обычный | язык определён по доменной зоне (`.nl`, `.de`, `.co.uk`…) или выбран вами раньше | ничего |
| 🟡 **жёлтый** | язык угадан по тексту сайта донора (для `.com`, `.net`, `.org`…) | глянуть; если верно — ничего, генерировать можно |
| 🔴 **красный** | язык определить не удалось (например, сайт не открылся) | выбрать язык в списке |

- **Язык запоминается для донора.** Выбрали один раз, и он сразу встаёт во все строки этого донора, а при следующих вставках подставится сам.
- **Язык ссылки и бренд запоминаются для проекта.** Бренд берётся из домена проекта: `betano-nl.com` → **Betano**. Если бренд определился неверно, исправьте его один раз на вкладке **Проекты**.
- **Откуда взят язык**, видно при наведении мыши на поле языка донора.

### Шаг 3. Сгенерировать

Нажмите **«Сгенерировать (N)»**, где N — сколько задач готово. Статьи пишутся по одной, сверху видна полоса прогресса: сколько готово и сколько примерно осталось.

В строке задачи видно, что происходит прямо сейчас:

| Надпись | Что значит |
|---|---|
| `пишу статью · 34 сек` | нейросеть пишет статью, обычно 7–50 секунд |
| `жду очереди запросов · 7 сек` | пауза между запросами, чтобы не превысить лимит Google в минуту. Это нормально |
| `исправляю 2 ош. (2 из 2)` | статья не прошла проверку, программа попросила нейросеть исправить |
| `пауза после лимита Google · 20 сек` | Google попросил подождать, программа ждёт и продолжит сама |

- Программу можно свернуть, она продолжит работать.
- **«Остановить»** дописывает текущую статью и останавливается. Недописанные задачи остаются «Новыми».
- Можно генерировать не все задачи сразу: отметьте нужные галочками слева и нажмите **«Перегенерировать»** над таблицей.

### Шаг 4. Проверить результат

После генерации у каждой задачи статус:

| Статус | Что значит | Что делать |
|---|---|---|
| ✅ **ОК** | статья прошла все проверки | можно размещать. Если есть «Мелочи: …», их удобно поправить руками при размещении |
| 🟡 **Проверить** | осталось серьёзное замечание даже после исправления | наведите мышь на статус и прочитайте замечание. Если это объём — можно оставить или поправить; если ссылка, бренд или структура — нажмите «Перегенерировать» |
| 🔴 **Ошибка** | статья не написана (Google не ответил, кончился лимит) | причина написана в строке; позже нажмите «Перегенерировать» |

**👁 Предпросмотр** показывает статью как страницу. Ссылка подсвечена жёлтым, сверху замечания проверки.

### Шаг 5. Разместить на сайте донора

1. Откройте вкладку **Статьи**: статьи сгруппированы по проектам.
2. Нажмите **«Копировать HTML»** у нужной статьи.
3. В админке донора переключите редактор в режим **HTML / «Текст» / «Код»** и вставьте (`Ctrl+V`).
   - WordPress, классический редактор: вкладка **«Текст»**.
   - WordPress, блочный редактор: блок **«Произвольный HTML»**, или «⋮» → «Редактор кода».
4. После публикации отметьте у статьи галочку **«Размещено»**. С галочкой «Скрыть размещённые» вверху такие статьи пропадут из списка, и останется только то, что ещё нужно разместить.

**Выгрузка всех статей одним файлом:** кнопки **«Скачать Word»** и **«Скачать HTML»** вверху вкладки «Статьи». В HTML-файле у каждой статьи своя кнопка «Копировать HTML»: удобно отправить файл коллеге или руководителю.

## 4. Какая статья получается

Программа следит, чтобы каждая статья соответствовала ТЗ:

Статья пишется по промпту, которым команда писала статьи вручную:

- **язык донора**, текст как от носителя языка, аналитическая подача, без воды;
- **`<h1>`** — уникальный тематический заголовок **без бренда**, не начинается с «Как» (How, Wie…);
- **7 разделов `<h2>`** с короткими подзаголовками, в каждом 5–6 длинных предложений;
- в трёх разных разделах — **маркированный список, таблица и нумерованный список**;
- **объём** 4500–6500 знаков с пробелами (меняется в настройках);
- **одна ссылка** на проект во **2-м разделе**, анкор слово в слово, без изменения падежа и регистра;
- **бренд** — 6 раз, по одному в разделах 1, 3, 4, 5, 6, 7 (во 2-м, где ссылка, и в заголовке бренда нет); где получается естественно — в форме «бренд + casino» на языке статьи; бренд выступает примером в аналитике и наблюдениях рынка, без обзора и преимуществ;
- **без** призывов играть, регистрироваться, вносить депозит, без бонус-кодов;
- **без** клише и «маркеров ИИ» из списка запрещённых фраз.

**Как вставляется ссылка.** Это зависит от того, совпадает ли язык донора с языком ссылки.

**Языки совпадают** (например, нидерландский сайт, ссылка на нидерландский проект): ссылка стоит в абзаце 2-го раздела, рядом уточнение вроде «игровая платформа» или «развлекательная платформа».

**Языки разные** (например, немецкий сайт, ссылка на нидерландский проект): во 2-м разделе отдельный абзац с цитатой специалиста из страны проекта, на языке ссылки и в кавычках. Ссылка внутри цитаты:

```
<h2>Warum bestimmte Ereignisse stärker im Gedächtnis bleiben</h2>
<p>Абзац по теме на языке статьи…</p>
<p>„Bijna-winsten zorgen vaak voor een sterkere emotionele reactie … een entertainmentplatform zoals <a href="…">QBet Casino</a>, waar …”, aldus gedragsanalist Jeroen van Dijk uit Nederland.</p>
<p>Короткое продолжение на языке статьи.</p>
```

Страна специалиста берётся из домена проекта (`betanoswitzerland.net` → Швейцария, `betano-nl.com` → Нидерланды). Имя специалиста вымышленное, в каждой статье новое.

**Проверка статьи.** Каждую статью программа проверяет сама:
- **серьёзные ошибки** (нет ссылки или изменён анкор, ссылка в 1-м разделе, цитата начинается со ссылки, бренд в заголовке или не упомянут вовсе, не тот язык, объём сильно мимо, абзац вместо подзаголовка) — программа сама просит нейросеть исправить, это стоит ещё одного запроса;
- **мелочи** (бренд не по разу в каждом разделе, нет формы «бренд + casino», раздел короче 600 знаков, заголовок начинается с «Как», список и таблица в одном разделе, слово со смешанными латинскими и русскими буквами) — только пишутся в замечаниях, запрос не тратится;
- что-то программа исправляет сама: точный анкор и адрес ссылки, лишнюю разметку.

## 6. Настройки

| Настройка | По умолчанию | Что делает |
|---|---|---|

| **Температура** | 0.9 | «творчество» нейросети: меньше — суше и однообразнее, больше — разнообразнее |
| **Примеры удачных тем** | 5 примеров | по одной в строке; нейросеть придумывает темы в похожем стиле |
| **Запрещённые фразы** | список клише | по одной в строке; программа проверяет каждую статью. Добавляйте по замечаниям руководителя |

Если не уверены, оставьте всё по умолчанию: программа настроена под бесплатный тариф.

## 7. Лимиты: сколько статей в день

На бесплатном тарифе Gemini главное ограничение — **запросов в день на каждую модель** (обычно 20). Одна статья — 1–2 запроса. Значит, одна модель даёт примерно **10–20 статей в день**. Когда она кончается, программа сама переключается на резервную.

- Свои лимиты смотрите в AI Studio: **Dashboard → Rate limits** (колонка RPD — запросов в день).
- Когда кончатся все модели, генерация остановится с сообщением **«Дневной лимит … исчерпан»**. Недописанные задачи останутся «Новыми»: продолжайте на следующий день, лимит обновляется раз в сутки.
- **Экономьте запросы:** перед генерацией проверяйте языки (жёлтые и красные строки), чтобы не перегенерировать потом. Не включайте строгую проверку без нужды.

## 8. Частые вопросы и проблемы

**Строка красная, «Нужен язык».** Выберите язык донора или язык ссылки в строке. Он запомнится для донора или проекта.

**Сайт донора не открылся, язык не угадан.** Бывает у сайтов с проблемным SSL-сертификатом или защитой от ботов. Выберите язык вручную один раз.

**Бренд определился неправильно** (например, `Thebahigocasino` вместо `Bahigo`). Вкладка **Проекты** → исправьте бренд → дальше все новые статьи этого проекта пойдут с правильным брендом. Уже написанные статьи перегенерируйте.

**Много статусов «Проверить».** Наведите мышь на статус, чтобы прочитать замечание. Объём на 20–30 слов больше или меньше нормы — обычно можно оставить. Ссылка, бренд, структура — «Перегенерировать».

**«Ошибка: Google не ответил».** Сервер Google был перегружен. Программа повторяет запрос один раз, потом ставит «Ошибка» и идёт дальше, чтобы одна статья не держала очередь. Перегенерируйте позже.

**«Ключ не работает (400 / 403)».** Ключ скопирован не целиком или удалён в AI Studio. Создайте новый и вставьте заново.

**«Модель недоступна на бесплатном тарифе (лимит 0)».** Эта модель не работает на бесплатном ключе. Программа сама перейдёт на следующую резервную. Если так со всеми — проверьте список моделей в настройках (кнопка «Проверить» покажет доступные).

**Программа «висит».** Посмотрите на строку «В работе»: если секунды тикают, программа работает. Пауза до 90 секунд после лимита Google — нормально.

**Можно ли работать вдвоём на одном компьютере?** Можно, но данные общие (одна учётная запись Windows — одна папка данных), и лимит ключа тоже общий.

## 9. Данные, резервная копия, обновление

**Где хранятся данные.** Только на вашем компьютере, в файле:

```
%APPDATA%\Генератор статей\data.json
```

Вставьте этот путь в адресную строку Проводника. В файле задачи, статьи, проекты, языки доноров, настройки и **ваш ключ API**.

- **Резервная копия:** закройте программу и скопируйте `data.json` в надёжное место. Восстановление — положить файл обратно.
- **Не отправляйте `data.json` целиком другим людям**: в нём ваш ключ.

**Обновление на новую версию:**
1. Закройте программу.
2. Скачайте новый zip из [Releases](../../releases).
3. Удалите старую папку `ArticleGenerator` и распакуйте новую на её место. Ярлык продолжит работать, если путь тот же.

Данные хранятся отдельно от папки программы, поэтому все задачи, статьи и ключ сохранятся.

## Для разработчика

Electron-приложение: `main.js` (окно, файлы, сеть), `preload.js`, `src/core.js` (языки, бренд, промпт, проверка статьи), `src/app.js` (интерфейс и очередь генерации).

- **Проверка логики на мок-Gemini** (реальный лимит не тратится):
  `set ELECTRON_RUN_AS_NODE=1`, затем `"%LOCALAPPDATA%\Programs\ArticleGenerator\ArticleGenerator.exe" test\run.js`
- **Тестовый запуск из исходников:** `ЗАПУСК ТЕСТА.bat` (отдельная копия программы и отдельные данные).
- **Сборка zip для Releases:** `tools\build.js <тег>`, например `tools\build.js v1.2.0` → `dist\ArticleGenerator-1.2.0-win-x64.zip`. Нужна установленная программа: из неё берутся Electron и библиотеки.

ГЕНЕРАТОР СТАТЕЙ

Запуск: двойной клик по ArticleGenerator.exe
(ярлык: правый клик по файлу -> Отправить -> Рабочий стол (создать ярлык)).

Если Windows покажет «Система Windows защитила ваш компьютер»:
нажмите «Подробнее» -> «Выполнить в любом случае». Программа не подписана сертификатом, это нормально.

Первый запуск: Настройки -> вставьте API-ключ Gemini (aistudio.google.com -> Get API key) -> «Проверить».
Данные (задачи, статьи, проекты, ключ) хранятся только на этом компьютере:
%APPDATA%\Генератор статей\data.json

Полная инструкция и разница версий — README.md в репозитории на GitHub.
